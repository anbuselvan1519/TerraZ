# ============================================================
#  Installation Notes
#  ------------------
#  1. Python 3.10 – 3.12 recommended (tested on 3.12).
#
#  2. Install all runtime deps:
#       pip install -r requirements.txt
#
#  3. llama_cpp_python requires a C++ compiler.
#     Pre-built wheels for Windows (CPU-only):
#       pip install llama-cpp-python --prefer-binary
#     For GPU (CUDA) acceleration:
#       set CMAKE_ARGS=-DLLAMA_CUBLAS=on
#       pip install llama-cpp-python --no-binary llama_cpp_python
#
#  4. torch wheels for CPU-only (smaller download):
#       pip install torch==2.2.2 torchvision==0.17.2 --index-url https://download.pytorch.org/whl/cpu
#
#  5. geopandas / pyproj on Windows may need:
#       pip install geopandas --prefer-binary
#
#  6. LLaMA model file must be placed at:
#       projects/llama.cpp/models/llama-3.2-1b-instruct-q4_k_m.gguf
#     (or update MODEL_PATH in llama_wrapper.py)
#
#  7. Run the app:
#       streamlit run app.py
